PYTHON LEARNING ASSISTANT WEBSITE

1. Copy the contents of this website folder into your existing project website/ folder.
2. Activate the website virtual environment: source .venv/bin/activate
3. Install dependencies: pip install -r requirements.txt
4. Run: python app.py
5. Open http://127.0.0.1:5000 in your browser.
6. Create an account from the registration page.

NOTES
- The exact 150 quiz questions were extracted from your uploaded src/main.py.
- Lessons 11-23 are loaded from the original lesson files copied into data/.
- Lessons 1-10 remain embedded in src/main.py and are not yet migrated into website lesson pages. Their original code is not changed.
- This is a local development starter. Change app.secret_key and use production settings before deployment.
